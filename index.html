01 · BEHAVIORAL SIGNALS

Browsing and cart activity, captured in real time

Each product view and add-to-cart sends a commerce XDM event. In production, Audience Manager turns a run of these into traits like "trail-running shoppers" or "cart abandoners," which downstream campaigns can target against.

02 · IDENTITY RESOLUTION

Tie the behavior to a known person

Anonymous browsing signals are useful, but Audience Manager gets far more valuable once a session is tied to a known identity. Submitting this form adds an email to the XDM identityMap, so every event on this visit — past and future — resolves to the same profile.

✓ Identity attached — check the console panel above.

Demo only — nothing is stored or emailed. The submission just demonstrates the identity payload shape.

03 · MAKE THIS SEND FOR REAL

Three edits before this streams to your org

The page ships with placeholder IDs, so it logs the exact payloads without erroring against a real org. Swap in your own values and it starts landing in your datastream.

01

Create a datastream

In the Adobe Experience Platform Data Collection UI, create a datastream and enable the Audience Manager (legacy) or Edge Segmentation service on it.

02

Drop in your IDs

Replace edgeConfigId and orgId in the script at the bottom of this file with the datastream ID and IMS Org ID shown in that UI.

03

Map traits in AAM

Back in Audience Manager, build trait rules against the incoming commerce and identityMap fields, then group traits into segments to activate.
